## Featured Projects

### Multi-Agent RAG E-commerce After-sales Customer Service

An intelligent after-sales customer service system built around **Multi-Agent orchestration**, **RAG retrieval**, **memory management**, and **automatic evaluation**.

**Tech:** Python, FastAPI, RAG, Redis, ChromaDB, MCP, Tool Calling, Docker Compose

- Designed a three-way intent recognition strategy combining LLM, Embedding, and Pattern matching
- Built a ChromaDB-based RAG knowledge base with query rewriting, parallel retrieval, deduplication, and LLM reranking
- Implemented Redis + ChromaDB memory layers for working memory, history summarization, and user profile extraction
- Built Multi-Agent routing with intent routing, performance routing, fallback handling, and parallel task collaboration
- Added monitoring feedback using success rate and latency to adjust agent routing scores dynamically
- Implemented an LLM-as-Judge evaluation flow for response scoring, regression checks, and optimization suggestions

---

### TrustDeskAI

A Multi-Agent RAG customer service system for travel and e-commerce scenarios.

**Tech:** Python, LangGraph, LangChain, RAG, Qdrant, Uvicorn, LangSmith, aiohttp

- Built a LangGraph-based Multi-Agent service workflow for flights, hotels, car rental, travel recommendations, and e-commerce support
- Designed a main Agent + specialized Assistant collaboration pattern using function calls and task handoff
- Built a multi-collection Qdrant RAG knowledge base covering data cleaning, chunking, embedding, vector indexing, and semantic retrieval
- Designed a risk-aware tool execution mechanism for sensitive operations such as booking changes, cancellations, and reservations
- Added LLM guardrails for jailbreak detection, business relevance checks, and low-risk request pass-through
